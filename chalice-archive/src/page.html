          Description

          In sections, each with an optional heading. A whole Total RP 3 description can be pasted into one section; its markup carries over.

          Formatting, as in Total RP 3
          {h1}Title{/h1}
          A heading. {h2} and {h3} are smaller. Add :c or :r to centre it or align it right, as in {h2:c}.
          {p:c}Text{/p}
          A centred paragraph. {p:r} aligns it right.
          {col:ffd100}Text{/col}
          Coloured text. The game's colour codes (|cffffd100Text|r) work too. Pale colours are darkened so they stay readable on parchment.
          {link*https://…*Text}
          A link. Only http and https addresses become links.
          A blank line
          Starts a new paragraph. A single line break stays a line break.

          Icons and images ({icon:…}, {img:…}) are game files, so they are left out.
